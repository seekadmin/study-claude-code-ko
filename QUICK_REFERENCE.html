/rewind

고급 기능

# 설정 파일(.claude/settings.json)에서 구성
# 09-advanced-features/config-examples.json 참고

# 계획 모드
/plan Task description

# 권한 모드(--permission-mode 플래그 사용)
# manual             - 모든 작업에 대해 승인 요청(구성 값 "default", v2.1.200부터 "manual"이 별칭)
# acceptEdits        - 파일 편집은 자동 승인, 그 외는 승인 요청
# plan               - 읽기 전용 분석, 수정 없음
# auto               - 백그라운드 분류기가 권한을 자동 결정
# dontAsk            - 사전 승인된 도구만 실행, 나머지는 모두 거부
# bypassPermissions  - 모든 작업 자동 승인(--permission-mode bypassPermissions, --dangerously-skip-permissions와 동일)

# 세션 관리
/resume                # 이전 대화 이어서 진행(인수 없으면 과거 세션 선택기)
/rename "name"         # 현재 세션 이름 변경
/fork [prompt]         # 대화를 새 백그라운드 세션으로 복사하고 여기서 계속 작업
/subtask <task>        # 대화를 상속하고 결과를 보고하는 포크된 서브에이전트 생성
/branch [name]         # 원본을 보존한 채 대화 사본으로 전환
claude -c              # 가장 최근 대화 이어서 진행
claude -r "session"    # 이름 또는 ID로 세션 재개

📋 기능 요약표

기능 설치 위치 사용 방법
Slash Commands (60+) .claude/commands/*.md /command-name
Memory ./CLAUDE.md 자동 로드
Skills .claude/skills/*/SKILL.md 자동 호출
Subagents .claude/agents/*.md 자동 위임
MCP .mcp.json(프로젝트) 또는 ~/.claude.json(사용자) /mcp__server__action
Hooks (33개 이벤트) ~/.claude/hooks/*.sh 이벤트 기반 실행(5가지 유형)
Plugins /plugin install 사용 모든 기능을 번들로 제공
Checkpoints 내장 Esc+Esc 또는 /rewind
Planning Mode 내장 /plan <task>
Permission Modes (6) 내장 --allowedTools, --permission-mode
Sessions 내장 /resume, /rename, /branch, /fork
Background Tasks 내장 백그라운드 실행
Remote Control 내장 claude --remote-control 또는 /remote-control
Web Sessions 내장 claude --cloud "task"
Git Worktrees 내장 claude -w <name>
Auto Memory 내장 ~/.claude/projects/<project>/memory/에 자동 저장
Task List 내장 Ctrl+T(체크리스트), /tasks(백그라운드 작업)
Bundled Skills 내장 /batch, /claude-api, /code-review [low\|medium\|high\|xhigh\|max\|ultra] [--fix] [--comment] [pr#\|branch\|path] (Claude가 스스로 시작할 수도 있으며 v2.1.246부터 모든 환경에서 가능. 수준을 지정하지 않으면 마지막으로 입력한 수준을 재사용, v2.1.223), /simplify (정리 전용 리뷰. v2.1.154부터 다시 /code-review와 별도 기능), /debug, /fewer-permission-prompts, /loop, /run (v2.1.145+), /run-skill-generator (v2.1.145+), /verify (v2.1.145+, v2.1.215부터 명시적 호출 전용 — Claude가 스스로 실행하지 않음)

주요 기능

기능 설명 사용 방법
Auto Mode 백그라운드 분류기를 이용한 완전 자율 실행. v2.1.207부터 Bedrock/Vertex/Foundry에서 기본적으로 사용 가능 Shift+Tab으로 모드 전환 또는 --permission-mode auto
Channels Discord 및 Telegram 통합 --channels 플래그, Discord/Telegram 봇
Voice Dictation 음성으로 명령과 컨텍스트 입력 /voice 명령
Output Styles Claude의 역할, 어조, 기본 응답 형식 변경 /config → Output style 또는 outputStyle 설정. 기본 제공: Default, Proactive, Explanatory, Learning, Concise

WebSearch Cap and Subagent Fan-Out Limits (v2.1.212, v2.1.219에서 확장) 세션당 WebSearch 호출 200회(-p와 Agent SDK에서는 턴당). v2.1.290부터 대화형 세션에서는 시간당 100회씩 다시 채워짐. 동시 서브에이전트 상한(기본값 20)은 v2.1.217에서 추가. v2.1.219부터 서브에이전트는 기본적으로 깊이 3까지 중첩 서브에이전트를 생성할 수 있음(v2.1.217에서는 중첩이 비활성화되어 있었음). 세션당 서브에이전트 200개 생성 상한은 v2.1.224에서 제거되어, 이제 세션당 전체 서브에이전트 수에 제한이 없음 CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION(기본값 200, /clear로 초기화), CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR(대화형 기본값 100, -p에서는 0), CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS(기본값 20), CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH(기본값 3, 1로 설정하면 비활성화)

Restricted Mode (v2.1.248+) --tools가 개별적으로 지정하지 않는 한(default 프리셋으로는 안 됨) 명령어나 코드를 실행하는 기본 제공 도구(Bash, PowerShell 등)와 WebFetch를 제외하고, 사용자·프로젝트·로컬 설정을 무시하며(관리되는 설정과 --settings는 계속 적용), 파일 도구를 작업 디렉터리로 제한하고, bypassPermissions와 클라우드 세션을 거부 claude --restricted 또는 CLAUDE_CODE_RESTRICTED=1
Subagent Cache TTL (v2.1.248+) 에이전트 프런트매터의 experimental.cacheTtl 필드로 서브에이전트 프롬프트 캐시 유지 시간 설정 에이전트 프런트매터에 experimental:과 cacheTtl: "5m"(또는 "1h") 추가. Subagents 참고
Forced Subagent Model (v2.1.257+) CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1로 CLAUDE_CODE_SUBAGENT_MODEL이 에이전트 프런트매터를 재정의. v2.1.251부터 이 환경 변수는 기본적으로 우선하지 않으며, 이 값을 설정하지 않으면 프런트매터(model: inherit 포함)가 우선함 CLAUDE_CODE_SUBAGENT_MODEL=sonnet CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1 claude
