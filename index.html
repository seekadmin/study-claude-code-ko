이 가이드를 써야 하는 이유

공식 문서는 무엇을 알려 줍니다.
이 가이드는 어떻게를 보여 줍니다.

기본은 시각 자료

Mermaid 다이어그램으로 각 기능의 내부 동작을 보여 주므로 어떻게뿐 아니라 왜까지 이해할 수 있습니다.

복사해 쓰는 템플릿

실무에 바로 쓸 수 있는 슬래시 명령어, CLAUDE.md 파일, 훅 스크립트, MCP 설정, 플러그인 번들을 제공합니다 — 오늘 바로 프로젝트에 넣어 보세요.

단계별 학습 경로

학습자에게 필요한 순서로 배열한 10개 모듈로 11–13시간 만에 입문자에서 파워 유저가 됩니다. 다음에 무엇을 배울지 고민할 필요가 없습니다.

자가 진단 내장

Claude Code 안에서 /self-assessment 또는 /lesson-quiz를 실행해 부족한 부분을 찾고 맞춤 학습 경로를 받으세요.

공식 문서와 이 가이드 비교

같은 도구, 다른 역할

이 가이드는 공식 문서를 보완합니다 — 공식 문서는 레퍼런스이고, 이 가이드는 커리큘럼입니다.

공식 문서 이 가이드
형식 레퍼런스 문서 Mermaid 다이어그램을 곁들인 시각적 튜토리얼
깊이 기능 설명 내부 동작 원리
예제 기본 코드 조각 바로 쓸 수 있는 실무용 템플릿
구성 기능별 구성 단계적 학습 경로(입문에서 고급까지)
온보딩 스스로 학습 예상 소요 시간이 포함된 안내형 로드맵
자가 진단 없음 맞춤 학습 경로를 만들어 주는 대화형 퀴즈
