# MCP란? 초보자를 위한 설명

## 한 줄 요약

**MCP(Model Context Protocol)는 AI가 외부 도구와 데이터에 접속하는 방법을 정해 둔 공통 규격입니다.** AI용 USB-C 포트라고 생각하면 됩니다.

## 왜 필요한가요?

AI(Claude 등)는 기본적으로 대화창 안에서만 일합니다. 내 파일, 데이터베이스, GitHub, Slack 같은 외부 서비스는 직접 볼 수 없습니다.

예전에는 AI와 서비스를 연결할 때마다 개별 연동 코드를 따로 만들어야 했습니다. AI가 N개, 서비스가 M개라면 N×M개의 연동이 필요했습니다. MCP는 이 연결 방식을 하나로 통일해서, 한 번 만든 연동을 어떤 AI 앱에서나 쓸 수 있게 합니다.

## 구성 요소

| 구성 요소 | 역할 | 예시 |
|-----------|------|------|
| **호스트(Host)** | 사용자가 쓰는 AI 앱 | Claude Code, Claude Desktop |
| **클라이언트(Client)** | 호스트 안에서 서버와 통신하는 부분 | 앱이 자동으로 관리 |
| **서버(Server)** | 도구와 데이터를 제공하는 작은 프로그램 | GitHub 서버, 파일시스템 서버 |

MCP 서버가 제공하는 기능은 크게 세 가지입니다.

- **도구(Tools)**: AI가 실행할 수 있는 동작 (예: 이슈 만들기, 파일 쓰기)
- **리소스(Resources)**: AI가 읽을 수 있는 데이터 (예: 문서, DB 레코드)
- **프롬프트(Prompts)**: 미리 만들어 둔 작업 템플릿

## 동작 예시

"이번 주에 열린 GitHub 이슈를 요약해 줘"라고 요청하면 다음 순서로 진행됩니다.

1. AI가 연결된 GitHub MCP 서버에 어떤 도구가 있는지 확인합니다.
2. 이슈 목록 조회 도구를 호출합니다.
3. 서버가 GitHub에서 데이터를 가져와 돌려줍니다.
4. AI가 결과를 읽고 요약해서 답합니다.

## Claude Code에서 써 보기

MCP 서버는 명령어 한 줄로 추가할 수 있습니다. 아래 서버 주소는 예시입니다.

```bash
# HTTP 방식의 원격 MCP 서버 추가
claude mcp add --transport http my-server https://example.com/mcp

# 등록된 서버 목록 확인
claude mcp list
```

프로젝트 단위로 공유하려면 저장소 루트의 `.mcp.json` 파일에 적습니다.

```json
{
  "mcpServers": {
    "my-server": {
      "type": "http",
      "url": "https://example.com/mcp"
    }
  }
}
```

## 주의할 점

- **신뢰할 수 있는 서버만 연결하세요.** MCP 서버는 내 파일이나 계정에 접근할 수 있습니다.
- **필요한 권한만 주세요.** 읽기만 필요하면 읽기 전용 토큰을 사용합니다.
- **서버를 너무 많이 켜지 마세요.** 도구 설명이 컨텍스트를 차지해서 AI의 정확도와 비용에 영향을 줍니다.

## 정리

| 질문 | 답 |
|------|----|
| MCP가 뭔가요? | AI와 외부 도구를 잇는 표준 규격 |
| 왜 쓰나요? | 연동을 한 번만 만들고 여러 AI 앱에서 재사용하려고 |
| 무엇을 할 수 있나요? | 파일, DB, GitHub, Slack 등을 AI가 직접 조회하고 조작 |
| 조심할 점은? | 신뢰할 수 있는 서버만, 최소 권한으로 |
