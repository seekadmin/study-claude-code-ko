MCP가 뭐야? (초보자용 ELI5)

한 줄 요약

MCP(Model Context Protocol)는 AI가 여러 도구와 데이터에 "같은 방식"으로 연결되게 해주는 약속(규칙)입니다.

비유: USB-C 단자

옛날에는 충전기마다 모양이 달랐습니다. 휴대폰, 이어폰, 카메라마다 전용 충전기가 필요했죠. 그런데 USB-C가 나오자 단자 하나로 다 연결됩니다.

MCP는 AI를 위한 USB-C입니다.

  • AI = 컴퓨터(또는 휴대폰)
  • 구글 캘린더, 파일, 데이터베이스, 슬랙 등 = 주변기기
  • MCP = 그 둘을 이어주는 공통 단자

MCP가 없다면?

AI는 똑똑하지만, 혼자서는 내 파일도, 내 일정도, 오늘 날씨도 볼 수 없습니다. 말만 잘하는 친구와 같습니다.

예전에는 AI와 도구를 연결하려면 도구마다 따로 연결 코드를 만들어야 했습니다. AI가 5종류, 도구가 10종류면 최대 50개를 만들어야 하죠. MCP가 있으면 각자 MCP만 지키면 서로 바로 연결됩니다.

세 명의 등장인물

식당에 비유해 봅시다.

역할 식당 MCP
호스트(Host) 손님 Claude 같은 AI 앱
클라이언트(Client) 주문을 전달하는 웨이터 호스트 안에서 서버와 대화하는 부분
서버(Server) 주방 실제 도구/데이터를 가진 쪽 (예: 파일 서버, GitHub 서버)

손님(AI)이 "내 일정 알려줘"라고 하면, 웨이터(클라이언트)가 주방(MCP 서버)에 전달하고, 결과를 가져다줍니다.

MCP 서버가 AI에게 주는 것

  1. 도구(Tools) — AI가 실행할 수 있는 동작. 예: "이슈 만들기", "파일 검색"
  2. 리소스(Resources) — AI가 읽을 수 있는 자료. 예: 문서, 데이터베이스 내용
  3. 프롬프트(Prompts) — 미리 만들어 둔 질문 양식

예시: 대화로 보기

나: 내 GitHub 저장소에서 열린 이슈 알려줘.

  1. AI가 "GitHub MCP 서버에 이슈 목록 도구가 있네" 하고 알아챕니다.
  2. MCP를 통해 도구를 호출합니다.
  3. 결과를 받아 나에게 쉬운 말로 알려줍니다.

Claude Code에서 써보기

# MCP 서버 추가하기 (예시)
claude mcp add my-server -- npx -y @modelcontextprotocol/server-filesystem /path/to/folder

# 연결된 MCP 서버 목록 보기
claude mcp list

명령어는 버전에 따라 다를 수 있으니 공식 문서를 함께 확인하세요.

주의할 점

  • MCP 서버는 내 파일과 계정에 접근할 수 있습니다. 믿을 만한 서버만 연결하세요.
  • AI가 도구를 쓰기 전에 허락을 구하는 설정을 켜 두면 안전합니다.

정리

  • MCP = AI와 도구를 잇는 공통 규격
  • 덕분에 AI가 "말만 하는 존재"에서 "실제로 일하는 존재"로 바뀝니다.
  • 한 번 만들어 둔 MCP 서버는 여러 AI 앱에서 재사용할 수 있습니다.
