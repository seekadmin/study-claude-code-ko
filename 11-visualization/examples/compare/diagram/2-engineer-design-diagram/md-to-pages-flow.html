● Markdown 수정 → GitHub Pages 반영

소스: .github/workflows/pages.yml, scripts/build_website.py, .pre-commit-config.yaml

반영 조건

  • main 브랜치 push 이후에만 배포됩니다. 로컬 브랜치 이름이 master이면 워크플로가 실행되지 않습니다.
  • 변경 파일이 **/*.md 등 paths 필터에 하나라도 걸려야 합니다.
  • PR 단계에서는 docs-check.yml만 돕니다. 배포는 머지 후입니다.

알아둘 점

  • 사이트는 .md가 유일한 원본입니다. HTML을 따로 고치지 않습니다.
  • gh-pages는 매번 새 단일 커밋으로 덮어씁니다. 이력은 남지 않습니다.
  • 다이어그램이 깨지면 pre-commit의 mermaid 훅에서 먼저 실패합니다.
